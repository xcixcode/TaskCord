# TaskCord

**깔끔하고 사용하기 쉬운, 나만의 할 일 목록(To-Do List) 체크리스트**

---

## 개요

본 프로젝트 **TaskCord**는 매일 해야 할 일을 잊지 않고 체계적으로 관리하기 위해 제작된 **개인용 체크리스트**입니다.  
사용자가 평소 자주 접하는 메신저 프로그램의 보기 편하고 세련된 UI를 참고하여 만들었기 때문에, 별도의 학습 없이도 아주 쉽고 직관적으로 사용할 수 있습니다.

복잡한 서버 설치나 빌드 과정이 필요 없으며, 웹 브라우저만 있으면 언제 어디서든 빠르게 실행하여 일상의 할 일들을 관리하고 완료한 항목들을 확인할 수 있습니다.

---

## 기술 스택
- **HTML5** - 웹 페이지의 전체적인 구조를 설계
- **CSS3** - 눈이 편안한 다크 테마 디자인 및 화면 크기에 맞춰 자동으로 변하는 반응형 레이아웃 구현
- **JavaScript** - 버튼을 눌러 목록을 추가하거나 내용을 지우는 등, 프로그램의 핵심 움직임과 기능 구현
- **Web Storage API** - 컴퓨터를 껐다 켜도 내가 적어둔 할 일 목록이 사라지지 않고 유지되도록 데이터를 저장하는 기술

---

## 주요 기능
- **직관적인 3단 레이아웃**: 메신저처럼 구성된 화면을 통해 할 일 목록을 쉽게 분류하고 확인할 수 있습니다.
- **진행 상황 시각화**: 내가 계획한 일을 얼마나 끝냈는지 원형 그래프를 통해 한눈에 파악할 수 있습니다.
- **똑똑한 검색**: 할 일이 너무 많아져도 검색창에 단어만 입력하면 원하는 항목을 바로 찾을 수 있습니다.
- **자동 저장**: 창을 닫아도 적어둔 할 일 목록은 사라지지 않고 브라우저에 안전하게 보관됩니다.
- **모바일 대응**: 컴퓨터뿐만 아니라 스마트폰 화면에서도 보기 좋게 자동으로 조정됩니다.

## 설치 및 실행

### GitHub Pages
https://xcixcode.github.io/TaskCord/

### 로컬에서 실행
1. 저장소를 클론하거나 파일을 다운로드하여 압축을 풉니다.
2. `index.html` 파일을 웹 브라우저(크롬, 엣지 등)로 엽니다.
3. 별도의 **서버 설정이나 복잡한 설치 과정 없이** 브라우저에서 바로 사용 가능합니다.
